# Unlock Your Charisma — שחרר את הכריזמה

אפליקציית React (RTL מלא, עברית) לאימון יכולות ורבליות. 13 שיעורים, כל שיעור בנוי כארבע שכבות: **עיקרון → כללי פעולה → מאגר מידע → תרגול תרחישים**.

## הרצה

```bash
cd app
npm install
npm run dev      # http://localhost:5173
npm run build    # בנייה ל-dist/
npm run preview  # תצוגה מקדימה של הבנייה
```

## הוספת שיעור — ללא נגיעה בקוד

כל שיעור הוא קובץ JSON נפרד בתיקייה `src/data/lessons/`.
כדי להוסיף שיעור: צרי קובץ חדש (למשל `lesson2.json`). האפליקציה טוענת אוטומטית את כל הקבצים בתיקייה וממיינת לפי `id`.

### מבנה קובץ שיעור

```json
{
  "id": 2,
  "title": "כותרת בעברית",
  "titleEn": "English Title",
  "duration": "11 min",
  "principle": "משפט עיקרון אחד.",
  "rules": ["כלל 1", "כלל 2", "כלל 3"],
  "knowledge": ["פסקת מאגר מידע 1", "פסקה 2"],
  "scenarios": [
    { "situation": "תיאור המצב", "prompt": "מה תגידי?", "example": "דוגמה לתגובה טובה" }
  ]
}
```

- `id` — מספר ייחודי (קובע את הסדר).
- `knowledge` — אופציונלי. אם ריק/חסר, שכבת מאגר המידע לא תוצג.
- `scenarios` — כל תרחיש: מצב, שאלה, ותשובת דוגמה שנחשפת בלחיצה על "הצג דוגמה".

כרגע קיים `lesson1.json` בלבד עם תוכן לדוגמה. החליפי אותו והוסיפי את שאר השיעורים.

## שמירה

סטטוס השיעורים (פתוח/הושלם) נשמר ב-localStorage (מפתח `uyc_status_v1`). שיעור מסומן "הושלם" אוטומטית בסיום התרחיש האחרון. אין הרשמה ואין שרת.
